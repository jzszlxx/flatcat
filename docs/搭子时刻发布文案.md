## 标题（20 字内建议）

桌面小猫 FlatCat：会跟着键盘抬爪的桌宠

## 一句话简介

用 C# 写的一只 2D 扁平桌宠：透明置顶、任意程序打字都会抬爪、摸头呼噜，还带番茄钟和多组闹钟。单文件 exe，不用装运行时，开源 MIT。

## 正文

### 做了什么

一只常驻桌面的小猫。它透明、置顶、不占任务栏，你能透过它看到下面的窗口；鼠标落在猫身上才接收点击，其余区域直接穿透给桌面。

- 在**任何程序**里敲键盘，它会对应抬左爪或右爪，头顶气泡显示键名（可关，或开隐私模式只显示左右手）
- 把鼠标移到头上按住 → 眯眼 + 呼噜声
- 按住身体拖走 → 位置记住，下次启动还在
- 闲置几分钟会睡着，中途随机舔爪、歪头

提醒这块做了四类：番茄钟（专注/休息可调，自动接续，记今日与累计）、喝水（5–240 分钟）、任意分钟倒计时、多组闹钟（按星期任选、贪睡补一次、系统提示音/猫叫/静音三种铃声），另外可以开整点报时。

设置是一个独立的四页窗口：外观 / 行为 / 提醒 / 系统。**双击猫、双击托盘图标、或者程序已在跑时再双击一次 exe**，都能把它叫出来。

### 怎么做的（可复刻的关键点）

**技术栈**：C# 5 + WinForms + GDI+，用 Windows 自带的 `csc.exe`（.NET Framework 4.8）编译。没有 SDK、没有 NuGet、没有第三方库，产物约 190 KB，双击即用。

**透明窗口**：没有用 `TransparencyKey`——它只能整像素抠色，边缘会毛刺，也不支持半透明。改用 `UpdateLayeredWindow` + `CreateDIBSection`，每帧把 32bpp 预乘 ARGB 位图推给窗口，得到真正的逐像素 alpha。

**点击穿透**：整窗常开 `WS_EX_TRANSPARENT`，每帧用渲染结果的 alpha 生成一张命中掩码；光标落在猫身上才摘掉穿透接收点击，否则点击直接落到下面的桌面图标。这样既不会挡住桌面，也不用做不规则 Region。

**不抢焦点**：`WS_EX_NOACTIVATE` + `ShowWithoutActivation`，点猫不会把前台程序切走。

**任意程序感知打字**：`SetWindowsHookEx(WH_KEYBOARD_LL)` 装在专用线程（先 `PeekMessage` 建消息队列再 `GetMessage` 循环）。回调里只读虚拟键码、写字段、`CallNextHookEx` 放行。键码只决定抬哪只爪、显示哪个键名，不记录字符、不落盘、不联网。

**猫是画出来的**：`GraphicsPath` 拼尾巴、后腿、梨形身体、前腿、头、耳、眼、鼻、胡须、小键盘；毛色由五个色槽驱动，配饰（铃铛/围巾/蝴蝶结/眼镜）、斑纹、异瞳是独立绘制层。

**计时为什么准**：不累加帧时间，而是记「结束时刻」，每帧比一次当前时间；休眠唤醒后剩余时间仍然正确。

**闹钟不重复响**：用「年月日时分 + 时间 + 标签」做指纹，同一分钟内比对相同就跳过。星期重复用位掩码 `bit0=周一 … bit6=周日`，与旧的 daily/weekdays 配置兼容。

### 踩过的坑

1. `Color.FromArgb(0x9C8D7A)` 单参重载会把 int 当 ARGB 解析，导致七种毛色 alpha=0 全透明——改成从 24 位 RGB 拆三通道。
2. `csc.exe` 经 MSYS 传参时，路径中间的 `src/` 会被吃掉，报「源文件未能打开」；改为 `cd src` 后用纯文件名编译。
3. PowerShell 5.1 按 ANSI 读无 BOM 的 UTF-8 脚本会乱码报语法错；取证脚本改用 Python + ctypes。
4. 固定宽 120 的 Label 会用自家背景色盖住右边的输入框；改成按字数估算宽度。
5. 编译时旧进程还锁着 exe，`CS0016 未能写入输出文件`——先结束进程再 build。

### 和参考项目的差别

参考的是开源项目 7paws（Tauri + three.js 的 3D 猫）。我们走 2D 矢量路线，把它的 7 毛色、配饰、斑纹、异瞳、隐私模式、左撇子、闲置小动作、番茄钟都做了，另外加了它没有的：多组闹钟（按星期/贪睡/铃声）、倒计时、喝水、整点报时、提醒历史、头顶时钟、双击即开的设置窗口。

没做：3D 渲染、MCP 捏猫、多只猫切换。
