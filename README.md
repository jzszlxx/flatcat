# 桌面小猫 FlatCat 1.6

一只会跟着你敲键盘的 2D 扁平风桌面宠物。透明窗口、置顶、不占任务栏，在**任何程序**里打字它都会抬爪，鼠标移到头上按住会呼噜，按住身体可以把它拖到任何地方。

1.6 加了**头顶金句**：猫头顶除了显示时钟，还可以显示一句话，两者二选一。内置 270 条，分哲思（84）、诗句（106）、原创金句（80）三类，勾选想看的分类，间隔 30 分钟到 24 小时可调，也能随时手动换一条。全部离线内置，不联网。

1.5.1 修的是 1.5 的一个 P0 缺陷：设置窗口里点过搜索框、再去点左侧导航，左栏会变成空白，点哪儿都切不了页。根因是搜索框失焦回填占位符时，占位符文本被当成过滤关键词，六个页名全不匹配，导航列表被清成 0 项。现在占位符不参与过滤，关键词一条都没命中时也会保留全部页并在状态栏提示。

1.5 动的是「这只猫像不像活的」和「设置窗口好不好用」两件事：

- **动画内核换成关键帧**：新增 16 段动作片段（呼吸、睡着、摸头、提醒、专注、舔爪、歪头、打字、惊醒、开心、落地、打哈欠、整点抖动、被拖走），四段缓动曲线带轻微过冲；基础循环与一次性动作分层叠加，动作播完自动回落，不再是一堆互相打架的阈值判断。
- **有表情了**：表情参数从 12 个扩到 23 个，加了笑眼、瞪眼、眉毛、微笑、张嘴、吐舌、腮红、耳朵转向、头部左右转、压扁回弹、身体前倾。摸头是笑眼+腮红，提醒是瞪眼+张嘴，打哈欠会吐舌头，拖起来会瞪眼+尾巴耷拉，放下有压扁回弹。
- **设置窗口换壳**：左侧导航 + 右侧内容区，顶部搜索框能直接过滤设置项（页名或页内控件文字命中都算），右侧是实时预览面板（改毛色/配饰/斑纹/异瞳立刻跟着变），底部状态栏显示当前状态。托盘菜单从 21 项平铺收成 7 项一级 + 二级分组。
- **三个不碰界面布置的小功能**：全局热键（Ctrl+Alt + S/R/L/P，被占用时整组自动换 Ctrl+Shift+Alt）、便携模式（exe 旁放个 `flatcat.portable` 就把配置收到 `data\`）、静默时段（到点只静音，气泡和日志照旧）。

1.4 的截图与电台/本地音乐、1.3 的闹钟与提醒全都还在。

技术路线对应 `7paws-桌面宠物复刻方案.html` 里的 **C 方案**：自研 2D 扁平版。

仓库地址：**https://github.com/jzszlxx/flatcat**

## 运行

解压后双击 `FlatCat.exe` 即可。无需安装、无需 .NET 运行时（用 Windows 自带的 .NET Framework 4.8）。

- 托盘出现猫头图标，猫在屏幕右下角。
- **双击猫身** 或 **双击托盘图标** → 打开设置窗口；右键也有「设置…」「截图」「电台」「本地音乐」等菜单。
- **程序已经在跑时，再双击一次 FlatCat.exe** 也会把设置窗口叫出来（不会启动第二只猫）。
- 命令行 `FlatCat.exe --settings 2` 可直接打开到指定页（0 外观 / 1 行为 / 2 提醒 / 3 系统 / 4 截图 / 5 媒体）。
- 左键按住**头**：呼噜 + 眯眼；按住**身体**：拖动。
- 猫身以外的透明区域，点击会直接落到下面的桌面图标上。
- 打字时头顶气泡会显示你按的键名（可在设置里关掉，或开隐私模式只显示左右手）。

配置写在 `%APPDATA%\FlatCat\settings.json`，设置窗口里有按钮直接打开所在文件夹。

## 设置窗口

窗口是「左导航 + 右内容 + 右预览」三栏：左边竖排六页，顶部搜索框输入关键词即过滤（页名命中或页内控件文字命中都会保留，例如输入「铃」能留下提醒页的铃声、行为页的呼噜声），右侧面板改毛色/配饰/斑纹/异瞳时实时重绘，底部状态栏显示保存与应用状态。

| 页 | 可调项 |
| --- | --- |
| 外观 | 毛色（7 种，带色块预览）、配饰（无 / 铃铛 / 围巾 / 蝴蝶结 / 眼镜）、大小 50%–160%、不透明度 40%–100%、小键盘、斑纹开关、异瞳、头顶显示（不显示 / 时间 / 金句）、金句分类与更换间隔 |
| 行为 | 闲置几分钟算睡着（0 = 不睡）、闲置随机小动作、左撇子模式、隐私模式、显示按键名、锁定点击穿透、呼噜声 |
| 提醒 | 番茄钟专注/休息 + 自动接续 + 今日完成数、喝水开关与间隔、倒计时、闹钟列表（编辑/删除/启停）、贪睡、整点报时、预览提醒 |
| 系统 | 开机自启、配置文件路径、全局热键开关、静默时段（起止整点）、配置位置（便携/漫游）、今日与累计番茄数、最近提醒记录 |
| 截图 | 截图时是否藏起小猫、截图后是否复制到剪贴板、保存目录、三个「马上试一下」按钮 |
| 媒体 | 电台列表（预置 + 自定义）与播放、新增/删除电台、音量、本地音乐文件夹与播放、当前播放状态 |

「确定 / 应用」会立即生效并写盘；「取消」走深拷贝回滚，不会留下半改的状态。设置窗口是 `TopMost`，不会被置顶的猫挡住。托盘菜单也收了一遍：一级只留「设置…」「显示 / 隐藏」「截图」「电台」「音乐」「外观」「陪伴与提醒」「关于」「退出」，「外观」下是大小/不透明度/毛色/闲置睡眠/小键盘，「陪伴与提醒」下是番茄钟/喝水/闹钟/呼噜/点击穿透/开机自启。

## 动画与表情

猫的表现由一层关键帧动画驱动，`src/Anim.cs` 里 16 个片段都写明了时长、循环与否和每条参数曲线：

| 场景 | 表现 |
| --- | --- |
| 闲置 | 呼吸正弦 + 尾巴缓慢左右摆 + 耳朵轻晃 + 随机眨眼（2.6–7.1 秒一次） |
| 摸头 | 笑眼、腮红、微笑、头轻微左右蹭，呼噜带身体轻微抖动 |
| 提醒 / 整点 | 瞪眼、张嘴、耳朵前竖、尾巴快摆，气泡暖橙色 |
| 专注 | 眼半睁、瞳孔朝下盯着键盘、嘴抿住 |
| 睡着 | 闭眼、身体下沉、头歪、耳朵放松 |
| 舔爪 | 抬左爪、低头、吐舌头、眼睛半闭（闲置随机动作，约 9–21 秒一次） |
| 歪头 | 头歪 11°、头部左右转、耳朵跟着动 |
| 打字 | 左爪/右爪/双爪快速抬起，带 Back 缓动的小过冲 |
| 惊醒 | 睁大眼、身体弹起、耳朵向前压 |
| 开心 | 笑眼 + 张嘴笑 + 腮红，一次性播完回落到基础状态 |
| 落地 | 压扁回弹（`squash` 从 1 收到 0） |
| 打哈欠 | 张嘴 95%、眼睛闭上、吐舌、头歪 |

实现上是「基础循环层 + 一次性动作层」叠加：基础层按状态切（闲置/睡着/摸头/提醒/被拖），动作层优先，播完自动清空回落。缓动有线性、缓出、缓入缓出、过冲四种。

## 头顶金句

猫头顶那块气泡除了显示时间，还可以显示一句话，两者二选一（也能都关掉）。数据全部内置在 exe 里，不联网、不调接口。

| 分类 | 条数 | 例子 |
| --- | --- | --- |
| 哲思 | 84 | 上善若水 · 学而不思则罔，思而不学则殆 |
| 诗句 | 106 | 海上生明月，天涯共此时 · 人生若只如初见 |
| 金句 | 80 | 把今天过好，就是最好的长期主义 |

- 三个分类可任意勾选，勾几个就从几个里抽；一个都不勾会自动退回全选。
- 更换间隔 30 分钟到 24 小时，步长 30 分钟，默认 60。到点自动换；也能随时点设置页的「立即换一条」，或右键「外观 → 头顶显示 → 换一句金句」。
- 抽句会避开上一条，不会连着重复。
- 长句按标点折成两行，气泡宽度固定，不会把字裁掉；第二行如果只剩标点会并回第一行。

数据来源：诗句与哲思都是**公有领域**原文（唐诗宋词、诗经、楚辞、论语、道德经、庄子、菜根谭、幽梦影、围炉夜话等，作者逝世均逾 70 年），其中诗经 / 论语 / 楚辞 / 幽梦影 / 纳兰性德 条目与 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT）收录的原文逐条比对过，出处以该库为准。金句为本站原创短句，随项目以 MIT 发布。

没有采用常见的「一言」句子库（`hitokoto-osc/sentences-bundle`）：它是 **AGPL-3.0**，传染性许可与本项目的 MIT 不兼容。

## 全局热键

设置「系统」页可开可关，默认开：

| 组合 | 作用 |
| --- | --- |
| `Ctrl+Alt+S` | 全屏截图 |
| `Ctrl+Alt+R` | 矩形选区截图 |
| `Ctrl+Alt+L` | 套索截图 |
| `Ctrl+Alt+P` | 播放 / 暂停当前音乐或电台 |

四个键被别的程序占用时，整组自动退到 `Ctrl+Shift+Alt+S/R/L/P` 再注册一次，避免只抢到一半、按下去行为不一致。自检里会真注册一遍再注销来验证（本机 `Ctrl+Alt+S/R` 已被占用，实测退到 `Ctrl+Shift+Alt` 后 4/4 可用）。

## 便携模式

默认配置在 `%APPDATA%\FlatCat\settings.json`。把整个程序放到 U 盘或同步盘，在 `FlatCat.exe` 同目录放一个空的 `flatcat.portable` 文件，配置就会改存到 `exe 目录\data\settings.json`，不碰用户漫游目录。设置「系统」页的「配置位置」会显示当前是哪种模式，旁边按钮直接打开对应目录。

## 静默时段

设置「系统」页可开，默认关（22 点 → 8 点）。开启后到点只把声音吞掉，气泡和「最近提醒」日志照旧写，所以不会错过提醒本身。跨午夜区间（如 22 → 8）按「大于等于起点或小于终点」判定，起止填同一个小时视为不启用。

## 截图怎么用

托盘右键 → 截图：

- **全屏**：直接抓整个虚拟屏（多显示器也一起抓）。
- **矩形选区**：屏幕变暗，按住左键拖出方框，松手出图；拖动时右上角实时显示尺寸。
- **不规则（套索）**：按住左键沿要截的轮廓描一圈，松手自动闭合，只保留圈内像素，圈外是真透明。

截图默认存到 `图片\FlatCat 截图`，文件名带时间戳（`FlatCat_20261126_093812.png`），不会覆盖旧图；同时会复制到剪贴板。按 `Esc` 或点右键可以取消。

**截图时隐藏小猫** 这一项在托盘菜单和设置的「截图」页都能勾。勾上后，截图前会先把窗口藏起来再抓屏，所以截出来的图里没有你自己；不勾则小猫会入镜。

## 电台与本地音乐

托盘右键 → 电台：内置 5 个频道（AsiaFM 亚洲热歌台、1766 线上电台、Anison 动漫音乐台、台中古典音乐台、古典音乐台 FM 97.7），点一下就播。子菜单里还有停止、暂停/继续、音量（25/50/75/100%）和「管理电台…」。

「管理电台…」跳到设置「媒体」页：填名称和流地址就能加自己的电台，选中后「删除选中」只删自定义项（预置项不会被动到）。自定义电台存在 `settings.json` 里，下次打开还在。

本地音乐：
- 「选择文件播放…」多选 mp3 / wav / wma / m4a / aac / flac；
- 「播放整个文件夹…」递归收录（最多 500 首），文件夹路径会记住，下次在设置「媒体」页能直接看到列表并播放其中一首；
- 菜单里有上一首 / 下一首 / 停止，一首放完自动接下一首。

## 闹钟怎么用

1. 双击猫 → 「提醒」页 → 右侧填时间、标签。
2. 「重复」那排勾星期几（`一二三四五六日`），全勾 = 每天，只勾一到五 = 工作日，一个都不勾 = 仅一次。
3. 选铃声：系统提示音 / 猫叫 / 静音。
4. 点「添加闹钟」。列表里双击某条可回填编辑，按钮会变成「保存修改」；「启用 / 停用」单独切换。
5. 列表下方实时显示「下次：07:30 起床 · 明天」这类预览。

到点后：猫睁眼竖耳摆尾、气泡显示 `07:30 起床`、按所选铃声发声，并写入「最近提醒」。若开了贪睡（默认 5 分钟），会再补一次提醒；右键菜单里也有「稍后提醒」手动触发。

## 番茄钟、喝水、倒计时、整点

- **番茄钟**：默认 25 分钟专注 + 5 分钟休息。专注结束自动接休息（可关），同时累计「今日番茄」和「累计番茄」。头顶气泡实时显示 `专注 24:59`。
- **喝水**：默认每 45 分钟，可改 5–240 分钟，到点提示「该喝水了」。
- **倒计时**：填 1–600 分钟点「开始」，气泡显示 `倒计时 09:59`。
- **整点报时**：可设定 0–24 点之间的时间段，每小时整点提示一次并播放猫叫。

提醒持续 9 秒：猫睁大眼、竖耳、尾巴摆快，气泡暖橙色；倒计时与键名是白色气泡。设置里的「预览提醒」能立刻看效果，不写配置。

## 构建

不需要安装任何 SDK：

```bash
bash build.sh
```

调用系统自带的 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，并引用系统自带的 WPF 程序集（`PresentationCore.dll`、`WindowsBase.dll`，供 MediaPlayer 播放音频），输出 `out/FlatCat.exe`（约 220 KB）。

资源（图标、呼噜声、猫叫）由 `tools/gen_assets.py` 程序化生成，不依赖外部素材：

```bash
python tools/gen_assets.py
```

## 代码结构

| 文件 | 职责 |
| --- | --- |

## 关键实现

**透明窗口**：不用 `TransparencyKey`（不支持半透明抗锯齿），改用 `UpdateLayeredWindow` + `CreateDIBSection`，每帧把 32bpp 预乘 ARGB 位图推给窗口，得到真正的逐像素透明和柔和边缘。

**透明处不挡桌面**：整窗默认带 `WS_EX_TRANSPARENT`。每帧用渲染结果的 alpha 生成命中掩码，光标落在猫身才摘掉穿透接收点击。

**不抢焦点**：窗口带 `WS_EX_NOACTIVATE` + `ShowWithoutActivation`，点猫不会把前台程序切走。

**任意程序里感知打字**：`SetWindowsHookEx(WH_KEYBOARD_LL)` 装在专用线程（带自己的消息循环）。回调里只读虚拟键码、写字段、`CallNextHookEx` 放行。键码只决定抬哪只爪和显示键名，不记录字符、不落盘、不联网。

**猫是画出来的**：`CatPainter` 用 `GraphicsPath` 拼尾巴、后腿、梨形身体、前腿、头、耳、眼、鼻、胡须、小键盘；毛色由 `Coats` 的五个色槽驱动，配饰与异瞳是独立绘制层。

**截图不把自己截进去**：要隐藏小猫时先 `Hide()` 并等一个消息循环 + 140ms，让桌面合成器把窗口擦掉；取景遮罩关闭后再等 180ms，才用 `Graphics.CopyFromScreen` 抓屏——否则会把半透明遮罩或残影带进图里。

**不规则截图**：把套索的点集求包围盒，转成相对坐标后 `GraphicsPath.AddPolygon`，`SetClip` 再 `DrawImage`，输出 32bpp ARGB，圈外是真透明（不是白色填充）。

**音频为什么单开线程**：WPF 的 `MediaPlayer` 依赖自己的 Dispatcher 泵，WinForms 主消息循环不泵它，事件不会回调。于是占一个 STA 线程跑 `Dispatcher.Run()`，播放调用一律 `BeginInvoke` 投递，状态用 volatile 字段回读给 UI。

**闹钟为什么不重复响**：记「年月日时分 + 时间 + 标签」指纹，同一分钟重复比对时相同就跳过；跨天自然变化。星期重复用位掩码 `bit0=周一 … bit6=周日`，与旧配置的 `daily / weekdays` 兼容。

**计时为什么准**：不累加帧时间，而是记住「结束时刻」，每帧比一次当前时间；休眠唤醒后剩余时间仍正确。

## 已知限制

- 只做了 Windows（`WS_EX_*` 与 `WH_*_LL` 钩子都是 Windows 专有）。
- 独占全屏游戏无法覆盖；无边框全屏、普通窗口可以。
- 未数字签名，首次运行 SmartScreen 可能提示“未知发布者”，选“仍要运行”。
- 全局键盘钩子的行为特征与键盘记录器相似，安全软件可能提示。代码只取键码、不记录内容、不联网，可自行审查源码。
- 内置播放器只认 `http://` 流；`https://` 流在部分机器上会让 MediaPlayer 内部抛错（本项目已实测），这类地址请用系统播放器打开。
- 电台流来自第三方，可能某天失效；届时在「媒体」页删掉或换成新地址即可，预置项也可直接换。
- 截图在锁屏、纯远程桌面等非交互桌面会话里会得到黑图，这是系统限制；正常桌面会话没问题。
- 闹钟精确到分钟；程序没运行时的闹钟不会补响（没有后台服务）。
- 运行中的番茄钟/倒计时/喝水计时不持久化，退出即清零；开关、时长、闹钟条目、番茄统计、电台与音量会保存。
- 贪睡是「到点后再提醒一次」，不是循环 snooze。
- 全局热键可能和常驻软件冲突：被占用时整组退到 `Ctrl+Shift+Alt`；两套都被占则只注册到哪几个算几个，设置「系统」页可整体关掉。
- 便携模式靠 exe 同目录的 `flatcat.portable` 标记文件判定，放了/删了都**要重启程序**才切换配置目录（当前进程内的路径已固定）。
- 静默时段只静音，不拦气泡和「最近提醒」记录；番茄钟、闹钟、整点报时、喝水都走同一道闸门。
- 金句是本地内置的固定集合，不会联网取新句、也不能在设置里增删；想加自己的句子改 `src/QuoteBank.cs` 后重新编译。
- 金句气泡最多两行、正文不超过 28 字，更长的句子会被截断加省略号——这是为了不压到猫耳朵。
- 还没做：MCP 捏猫、照片取色生成猫、多只猫切换、3D 渲染（架构上已留好配置层）。
- 高 DPI 下按系统 DPI 等比放大，不做逐显示器 DPI 跟踪。
