# 桌面小猫 FlatCat 1.3

一只会跟着你敲键盘的 2D 扁平风桌面宠物。透明窗口、置顶、不占任务栏，在**任何程序**里打字它都会抬爪，鼠标移到头上按住会呼噜，按住身体可以把它拖到任何地方。

1.3 版重点补齐了**设置与提醒**：双击猫（或双击托盘图标）直接打开设置窗口；闹钟可以编辑、按星期任选重复、贪睡补提醒、换铃声；另外加了整点报时、配饰、斑纹开关、异瞳、头顶时钟。

技术路线对应 `7paws-桌面宠物复刻方案.html` 里的 **C 方案**：自研 2D 扁平版。

仓库地址：**https://github.com/jzszlxx/-**

## 运行

解压后双击 `FlatCat.exe` 即可。无需安装、无需 .NET 运行时（用 Windows 自带的 .NET Framework 4.8）。

- 托盘出现猫头图标，猫在屏幕右下角。
- **双击猫身** 或 **双击托盘图标** → 打开设置窗口；右键也有「设置…」和「提醒 / 闹钟」菜单。
- **程序已经在跑时，再双击一次 FlatCat.exe** 也会把设置窗口叫出来（不会启动第二只猫）。
- 命令行 `FlatCat.exe --settings 2` 可直接打开到指定页（0 外观 / 1 行为 / 2 提醒 / 3 系统）。
- 左键按住**头**：呼噜 + 眯眼；按住**身体**：拖动。
- 猫身以外的透明区域，点击会直接落到下面的桌面图标上。
- 打字时头顶气泡会显示你按的键名（可在设置里关掉，或开隐私模式只显示左右手）。

配置写在 `%APPDATA%\FlatCat\settings.json`，设置窗口里有按钮直接打开所在文件夹。

## 设置窗口

| 页 | 可调项 |
| --- | --- |
| 外观 | 毛色（7 种，带色块预览）、配饰（无 / 铃铛 / 围巾 / 蝴蝶结 / 眼镜）、大小 50%–160%、不透明度 40%–100%、小键盘、斑纹开关、异瞳、头顶常显时间 |
| 行为 | 闲置几分钟算睡着（0 = 不睡）、闲置随机小动作、左撇子模式、隐私模式、显示按键名、锁定点击穿透、呼噜声 |
| 提醒 | 番茄钟专注/休息 + 自动接续 + 今日完成数、喝水开关与间隔、倒计时、闹钟列表（编辑/删除/启停）、贪睡、整点报时、预览提醒 |
| 系统 | 开机自启、配置文件路径、今日与累计番茄数、最近提醒记录、隐私说明 |

「确定 / 应用」会立即生效并写盘；「取消」走深拷贝回滚，不会留下半改的状态。设置窗口是 `TopMost`，不会被置顶的猫挡住。

## 闹钟怎么用

1. 双击猫 → 「提醒」页 → 右侧填时间、标签。
2. 「重复」那排勾星期几（`一二三四五六日`），全勾 = 每天，只勾一到五 = 工作日，一个都不勾 = 仅一次。
3. 选铃声：系统提示音 / 猫叫 / 静音。
4. 点「添加闹钟」。列表里双击某条可回填编辑，按钮会变成「保存修改」；「启用 / 停用」单独切换。
5. 列表下方实时显示「下次：07:30 起床 · 明天」这类预览。

到点后：猫睁眼竖耳摆尾、气泡显示 `07:30 起床`、按所选铃声发声，并写入「最近提醒」。若开了贪睡（默认 5 分钟），会再补一次提醒；右键菜单里也有「稍后提醒」手动触发。

## 番茄钟、喝水、倒计时、整点

- **番茄钟**：默认 25 分钟专注 + 5 分钟休息。专注结束自动接休息（可关），同时累计「今日番茄」和「累计番茄」。头顶气泡实时显示 `专注 24:59`。
- **喝水**：默认每 45 分钟，可改 5–240 分钟，到点提示「该喝水了」。
- **倒计时**：填 1–600 分钟点「开始」，气泡显示 `倒计时 09:59`。
- **整点报时**：可设定 0–24 点之间的时间段，每小时整点提示一次并播放猫叫。

提醒持续 9 秒：猫睁大眼、竖耳、尾巴摆快，气泡暖橙色；倒计时与键名是白色气泡。设置里的「预览提醒」能立刻看效果，不写配置。

## 构建

不需要安装任何 SDK：

```bash
bash build.sh
```

调用系统自带的 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，输出 `out/FlatCat.exe`（约 190 KB）。

资源（图标、呼噜声、猫叫）由 `tools/gen_assets.py` 程序化生成，不依赖外部素材：

```bash
python tools/gen_assets.py
```

## 取证命令

```bash
# 七状态拼图（含专注/喝水气泡）
out/FlatCat.exe --sheet sheet.png

# 七种毛色并排图
out/FlatCat.exe --coats coats.png

# 配饰与异瞳预览（无/铃铛/围巾/蝴蝶结/眼镜/异瞳）
out/FlatCat.exe --extras extras.png

# 自检：配置往返、深拷贝、设置窗口构造、钩子、时钟、闹钟匹配/星期/下次时间、按键名、渲染、配饰、异瞳
out/FlatCat.exe --selftest selftest.txt

# 直接打开设置到某一页（0 外观 / 1 行为 / 2 提醒 / 3 系统）
out/FlatCat.exe --settings 2

# 实跑取证：启动→读窗口样式→截图→单实例→收尾（需要桌面会话）
python tools/verify.py "<绝对路径>/out/FlatCat.exe" "<绝对路径>/out"
```

## 关键实现

**透明窗口**：不用 `TransparencyKey`（不支持半透明抗锯齿），改用 `UpdateLayeredWindow` + `CreateDIBSection`，每帧把 32bpp 预乘 ARGB 位图推给窗口，得到真正的逐像素透明和柔和边缘。

**透明处不挡桌面**：整窗默认带 `WS_EX_TRANSPARENT`。每帧用渲染结果的 alpha 生成命中掩码，光标落在猫身才摘掉穿透接收点击。

**不抢焦点**：窗口带 `WS_EX_NOACTIVATE` + `ShowWithoutActivation`，点猫不会把前台程序切走。

**任意程序里感知打字**：`SetWindowsHookEx(WH_KEYBOARD_LL)` 装在专用线程（带自己的消息循环）。回调里只读虚拟键码、写字段、`CallNextHookEx` 放行。键码只决定抬哪只爪和显示键名，不记录字符、不落盘、不联网。

**猫是画出来的**：`CatPainter` 用 `GraphicsPath` 拼尾巴、后腿、梨形身体、前腿、头、耳、眼、鼻、胡须、小键盘；毛色由 `Coats` 的五个色槽驱动，配饰与异瞳是独立绘制层。

**闹钟为什么不重复响**：记「年月日时分 + 时间 + 标签」指纹，同一分钟重复比对时相同就跳过；跨天自然变化。星期重复用位掩码 `bit0=周一 … bit6=周日`，与旧配置的 `daily / weekdays` 兼容。

**计时为什么准**：不累加帧时间，而是记住「结束时刻」，每帧比一次当前时间；休眠唤醒后剩余时间仍正确。

## 已知限制

- 只做了 Windows（`WS_EX_*` 与 `WH_*_LL` 钩子都是 Windows 专有）。
- 独占全屏游戏无法覆盖；无边框全屏、普通窗口可以。
- 未数字签名，首次运行 SmartScreen 可能提示“未知发布者”，选“仍要运行”。
- 全局键盘钩子的行为特征与键盘记录器相似，安全软件可能提示。代码只取键码、不记录内容、不联网，可自行审查源码。
- 闹钟精确到分钟；程序没运行时的闹钟不会补响（没有后台服务）。
- 运行中的番茄钟/倒计时/喝水计时不持久化，退出即清零；开关、时长、闹钟条目、番茄统计会保存。
- 贪睡是「到点后再提醒一次」，不是循环 snooze。
- 还没做：MCP 捏猫、照片取色生成猫、多只猫切换、3D 渲染（架构上已留好配置层）。
- 高 DPI 下按系统 DPI 等比放大，不做逐显示器 DPI 跟踪。
